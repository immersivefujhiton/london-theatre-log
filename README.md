# London Theatre Log

A one-page view of what's on and coming up at London theatres, and where the gaps are with nothing announced.

The page reads its data live from the London Theatre Log Google Sheet through an Apps Script web app (`?format=json`). Shows logged with the sheet's Google Form, or edited in the sheet directly, appear the next time the page is opened. This repository only holds the page itself (`index.html`), so it only needs changing when the design changes.
